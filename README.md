# 오행 (五行) — 사주 · 타로

첫 화면에서 **사주**와 **타로** 두 갈래를 고릅니다. 토스 앱처럼 깔끔한 디자인, 100% 클라이언트 사이드(API 키·서버 불필요).

- **사주** — 이름·생년월일·태어난 시간만 입력하면 **만세력으로 사주 원국을 자동 계산**하고, 오행 분포·십성·격국·용신·신살·7대 영성 지표로 분석해 풀이합니다. **두 사람의 궁합**도 볼 수 있습니다.
- **타로** — 9가지 주제(연애·미래·대인관계·재회·이직·사업·재물·진로·시험) 중 하나를 고르면, 검은 배경에 펼쳐진 **라이더-웨이트 78장**에서 세 장을 뽑아 정/역방향까지 반영해 풀이합니다. 주제마다 세 자리의 뜻이 다릅니다.

## 빠르게 실행

```bash
node server.js          # → http://localhost:4476/
```

또는 정적 호스팅(GitHub Pages·Netlify·Vercel)에 그대로 올리면 됩니다. 모든 계산이 브라우저에서 일어나므로 백엔드가 필요 없습니다.

## 무엇을 하나

1. **만세력 자동 변환** — 양력/음력(윤달 포함) 생년월일·시간 → 사주 4기둥(년·월·일·시주)
   - 절기는 VSOP87 태양황경, 음력은 Meeus 삭(신월)·무중치윤으로 천문 계산
   - 진태양시 보정(한국 표준시 역사 + 출생지 경도 + 균시차 + 서머타임), 자시(子時) 경계 학설 토글
2. **생년월일 유형** — 일간 물상(甲=큰 나무 … 辛=보석) × 태어난 계절 = **40조합**. "🔥 여름 화초형 — 뜨거운 날에도 쉽게 시들지 않는 사람" 처럼 결과 맨 앞에서 한눈에 잡아 줍니다
3. **분석** — 오행 분포, 십성, 7대 영성 지표(화개성·태극귀인·공망·편인·사고·칠살상관·壬癸丁子午卯酉), 영성 점수
4. **명리 이론 계층** — 통근(通根)·투간 기반 신강/신약 정밀 판정, 격국(格局), 용신(用神) 후보(억부+조후), 조후 한난조습, 십이운성, 신살(천을귀인·문창·역마·도화·양인·홍염·괴강·백호), 원국 내 형충회합
5. **둘의 궁합(宮合)** — 두 사람의 원국을 함께 펼쳐 6개 축(일간·일지·오행 보완·년지·월지+조후·신강약)으로 100점 환산. 네 기둥 대조표, 서로에게 어떤 십성인지, 조율 포인트와 실천 제안까지
6. **대운·세운** — 양남음녀 순행/역행, 절기 기반 대운수, 대운 10년 흐름 타임라인 + 세운(연운) 12년
7. **내장 자동풀이** — 영성 상담 프롬프트의 7섹션 구조를 따르는 한국어 풀이
8. **AI 프롬프트 복사** — 계산된 원국(+대운/세운)을 채운 프롬프트를 복사해 GPT·Claude에 붙여넣어 더 깊은 상담. 궁합 모드는 두 원국 + 관계 판정을 담은 **전용 궁합 프롬프트**
9. **이미지 저장·공유** — 결과를 사주 카드 이미지로 저장하거나 모바일에서 바로 공유(카톡 등). 공유 링크에 입력값이 담겨 링크만으로 결과 재현(궁합은 두 사람 모두)

### 타로

1. **주제별 스프레드** — 9가지 주제 각각이 **서로 다른 세 자리**를 갖습니다.
   예) 재회운 = `지난 관계가 남긴 것` / `지금 두 사람의 거리` / `재회의 가능성`,
   시험운 = `현재 실력` / `장애물` / `결과의 결`
2. **78장 전량 해석** — 라이더-웨이트 78장 × 9주제 × 정/역방향 = **1,404줄**을 카드마다 직접 작성했습니다. 어떤 카드를 뽑아도 고른 주제에 맞는 해석이 나옵니다.
3. **카드 뽑기** — 78장이 검은 배경에 **무지개처럼 휘어진 아치**로 펼쳐집니다. 좌우로 밀거나 스크롤하면 아치가 돌고, 꼭대기 한 장만 크게 확대돼 "지금 고를 카드"가 눈으로 확정됩니다(카드마다 번호 + `N번째 / 남은 M장` 카운터). 옆 카드를 눌러도 뽑히지 않고 가운데로 굴러오므로 잘못 고를 일이 없습니다. 뽑으면 카드가 아치에서 위로 빠져나와 슬롯으로 날아가고, 세 장이 모이면 순차적으로 뒤집혀 공개됩니다. 다시 섞기·알아서 뽑기 지원.
4. **역방향** — 실물 덱처럼 50% 확률로 뒤집혀 나옵니다(토글로 끌 수 있음). 역방향을 "나쁜 카드"로 쓰지 않고 안으로 향한 기운·지연·재검토·과잉의 반작용으로 읽습니다.
5. **세 장을 함께 보면** — 카드 하나씩으로는 안 보이고 세 장을 나란히 놓아야 보이는 것(메이저 아르카나 비중, 수트 쏠림, 역방향 개수)을 따로 제시합니다.
6. **타로 전용 AI 프롬프트** — 뽑은 세 장과 자리 뜻을 채운 프롬프트를 복사해 GPT·Claude에서 더 깊게 볼 수 있습니다.
7. **공유·저장** — 공유 링크(`?t=주제&c=카드3장`)로 같은 결과를 그대로 재현하고, 스프레드 카드뉴스 이미지로 저장할 수 있습니다.

### 귀인 지도

내 곁의 사람들이 나에게 **어떤 인연인지** 한 장의 지도로 모으는 기능입니다.

1. **다섯 유형** — 🌟 귀인 / 🤝 단짝 / 🌱 내 사람 / 🧭 오른팔 / ⚡ 호랑이 선생.
   십성(十星)을 기준선으로 삼고 오행 보완·일지 합충·천을귀인을 보정치로 얹어 판정합니다.
2. **서버 없이 굴러갑니다** — 지도를 만들면 링크가 생기고, 친구가 생일을 넣으면 관계 유형이 나옵니다.
   친구가 '결과 보내기' 링크를 보내 주면 그 링크를 열 때 내 지도에 쌓입니다.
   **개인정보가 서버로 가지 않는 대신, 지도는 지도를 만든 사람의 브라우저에만 저장됩니다.**
3. **방향이 있는 판정** — "내가 챙기는 사람"과 "나를 북돋는 사람"은 서로 반대 자리라, 관점을 뒤집으면 유형이 달라질 수 있습니다.
4. **점수를 매기지 않습니다** — 관계에 점수를 붙이면 사람을 줄 세우게 되므로 유형과 근거만 보여 줍니다.

배포는 [`DEPLOY.md`](./DEPLOY.md) 참조 (Netlify 드래그&드롭 1분, GitHub Pages 등).
명리 이론의 근거·채택 학설·의도적 제외 항목은 [`THEORY.md`](./THEORY.md)에 정리돼 있습니다. 타로의 전거·역방향 규약은 같은 문서 11장, 생년월일 유형(물상론)은 12장, 귀인 지도의 관계 판정은 13장에 있습니다.

- 음↔양력: KASI API 검증쌍(설날·윤달 포함) 일치
- 일주: `2000-01-07=갑자` 앵커 검증
- e2e 4기둥: 나무위키 표준예시·손흥민·노무현 등 일치

**명리 이론·궁합** (`tests/theory.test.mjs`, 273건)
- 십이운성: 일간 10종 × 12지지 순환 완전성 + 건록지 검산

**타로** (`tests/tarot.test.mjs`, 2,886건)

- 해석 완전성: 78 × 9주제 × 정/역 = **1,404줄이 하나도 비지 않았는지** · 정방향과 역방향 문장이 같지 않은지

## 면책

사주도 타로도 정답이 아니라 방향을 보는 지도입니다. 재미와 자기성찰의 참고로 사용하세요. 이 앱은 운명을 단정하지 않으며, 고통의 가능성도 성장과 실천의 언어로 풀이합니다.

타로 카드 이미지는 라이더–웨이트–스미스 덱(1909, A.E. Waite 감수 / Pamela Colman Smith 그림)으로 **퍼블릭 도메인**입니다. 해석은 A.E. Waite, *The Pictorial Key to the Tarot*(1910, 퍼블릭 도메인)를 전거로 한국어로 재서술했습니다.

자세한 구조·설계는 [`HANDOFF.md`](./HANDOFF.md) 참조.
