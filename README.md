# 오행 (五行) — 사주 오행 분석

이름·생년월일·태어난 시간만 입력하면 **만세력으로 사주 원국을 자동 계산**하고, 오행 분포·십성·7대 영성 지표로 분석해 풀이해 주는 웹/모바일 앱. 토스 앱처럼 깔끔한 디자인, 100% 클라이언트 사이드(API 키·서버 불필요).

## 빠르게 실행

```bash
node server.js          # → http://localhost:4476/
```

또는 정적 호스팅(GitHub Pages·Netlify·Vercel)에 그대로 올리면 됩니다. 모든 계산이 브라우저에서 일어나므로 백엔드가 필요 없습니다.

## 무엇을 하나

1. **만세력 자동 변환** — 양력/음력(윤달 포함) 생년월일·시간 → 사주 4기둥(년·월·일·시주)
   - 절기는 VSOP87 태양황경, 음력은 Meeus 삭(신월)·무중치윤으로 천문 계산
   - 진태양시 보정(한국 표준시 역사 + 출생지 경도 + 균시차 + 서머타임), 자시(子時) 경계 학설 토글
2. **분석** — 오행 분포, 십성, 신강·신약 근사, 7대 영성 지표(화개성·태극귀인·공망·편인·사고·칠살상관·壬癸丁子午卯酉), 영성 점수
3. **대운·세운** — 양남음녀 순행/역행, 절기 기반 대운수, 대운 10년 흐름 타임라인 + 세운(연운) 12년
4. **내장 자동풀이** — 영성 상담 프롬프트의 7섹션 구조를 따르는 한국어 풀이
5. **AI 프롬프트 복사** — 계산된 원국(+대운/세운)을 채운 프롬프트를 복사해 GPT·Claude에 붙여넣어 더 깊은 상담
6. **이미지 저장·공유** — 결과를 사주 카드 이미지로 저장하거나 모바일에서 바로 공유(카톡 등)

배포는 [`DEPLOY.md`](./DEPLOY.md) 참조 (Netlify 드래그&드롭 1분, GitHub Pages 등).

## 정확도

만세력 엔진은 70개 단위테스트를 통과합니다(`node tests/manse.test.mjs`):
- 절기 시각: KASI 기준 분 단위 일치(VSOP87)
- 음↔양력: KASI API 검증쌍(설날·윤달 포함) 일치
- 일주: `2000-01-07=갑자` 앵커 검증
- e2e 4기둥: 나무위키 표준예시·손흥민·노무현 등 일치

## 면책

사주는 정답이 아니라 방향을 보는 지도입니다. 재미와 자기성찰의 참고로 사용하세요. 이 앱은 운명을 단정하지 않으며, 고통의 가능성도 성장과 실천의 언어로 풀이합니다.

자세한 구조·설계는 [`HANDOFF.md`](./HANDOFF.md) 참조.
