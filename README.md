# 오행 (五行) — 사주 오행 분석 · 궁합

이름·생년월일·태어난 시간만 입력하면 **만세력으로 사주 원국을 자동 계산**하고, 오행 분포·십성·격국·용신·신살·7대 영성 지표로 분석해 풀이해 주는 웹/모바일 앱. **두 사람의 궁합**도 함께 볼 수 있습니다. 토스 앱처럼 깔끔한 디자인, 100% 클라이언트 사이드(API 키·서버 불필요).

## 빠르게 실행

```bash
node server.js          # → http://localhost:4476/
```

또는 정적 호스팅(GitHub Pages·Netlify·Vercel)에 그대로 올리면 됩니다. 모든 계산이 브라우저에서 일어나므로 백엔드가 필요 없습니다.

## 무엇을 하나

1. **만세력 자동 변환** — 양력/음력(윤달 포함) 생년월일·시간 → 사주 4기둥(년·월·일·시주)
   - 절기는 VSOP87 태양황경, 음력은 Meeus 삭(신월)·무중치윤으로 천문 계산
   - 진태양시 보정(한국 표준시 역사 + 출생지 경도 + 균시차 + 서머타임), 자시(子時) 경계 학설 토글
2. **분석** — 오행 분포, 십성, 7대 영성 지표(화개성·태극귀인·공망·편인·사고·칠살상관·壬癸丁子午卯酉), 영성 점수
3. **명리 이론 계층** — 통근(通根)·투간 기반 신강/신약 정밀 판정, 격국(格局), 용신(用神) 후보(억부+조후), 조후 한난조습, 십이운성, 신살(천을귀인·문창·역마·도화·양인·홍염·괴강·백호), 원국 내 형충회합
4. **둘의 궁합(宮合)** — 두 사람의 원국을 함께 펼쳐 6개 축(일간·일지·오행 보완·년지·월지+조후·신강약)으로 100점 환산. 네 기둥 대조표, 서로에게 어떤 십성인지, 조율 포인트와 실천 제안까지
5. **대운·세운** — 양남음녀 순행/역행, 절기 기반 대운수, 대운 10년 흐름 타임라인 + 세운(연운) 12년
6. **내장 자동풀이** — 영성 상담 프롬프트의 7섹션 구조를 따르는 한국어 풀이
7. **AI 프롬프트 복사** — 계산된 원국(+대운/세운)을 채운 프롬프트를 복사해 GPT·Claude에 붙여넣어 더 깊은 상담. 궁합 모드는 두 원국 + 관계 판정을 담은 **전용 궁합 프롬프트**
8. **이미지 저장·공유** — 결과를 사주 카드 이미지로 저장하거나 모바일에서 바로 공유(카톡 등). 공유 링크에 입력값이 담겨 링크만으로 결과 재현(궁합은 두 사람 모두)

배포는 [`DEPLOY.md`](./DEPLOY.md) 참조 (Netlify 드래그&드롭 1분, GitHub Pages 등).
명리 이론의 근거·채택 학설·의도적 제외 항목은 [`THEORY.md`](./THEORY.md)에 정리돼 있습니다.

## 정확도

```bash
npm test          # 만세력 80 + 이론·궁합 273 = 353개 단위테스트
npm run test:ui   # Playwright 렌더링 검증 (server.js 가 4476에 떠 있어야 함)
```

**만세력** (`tests/manse.test.mjs`, 80건)
- 절기 시각: KASI 기준 분 단위 일치(VSOP87)
- 음↔양력: KASI API 검증쌍(설날·윤달 포함) 일치
- 일주: `2000-01-07=갑자` 앵커 검증
- e2e 4기둥: 나무위키 표준예시·손흥민·노무현 등 일치

**명리 이론·궁합** (`tests/theory.test.mjs`, 273건)
- 십이운성: 일간 10종 × 12지지 순환 완전성 + 건록지 검산
- 신살 테이블: 천을귀인·문창·양인·역마·도화·화개 전건 대조
- 형충회합: 육합·삼합·방합·충·형·해·파·원진 전 쌍 + 오탐 방지(戊己 무충, 비자형 8지지)
- 궁합: 배점 합계 100 · 축별 범위 · 좌우 대칭성 · 시주 미상 처리 · 780쌍 분포 무결성
